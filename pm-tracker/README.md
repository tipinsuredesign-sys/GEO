# TIP Insure SEO — Project Tracker

เว็บติดตามงาน (Project Management) สำหรับคุมงานแก้ปัญหาจาก Technical Onsite Audit ของ www.tipinsure.com ทั้ง 30 ข้อ

## วิธีเปิดใช้
เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ (ดับเบิลคลิกได้เลย) — ไม่ต้องติดตั้งอะไร ไม่ต้องมีเซิร์ฟเวอร์

> ต้องเก็บ `index.html` กับ `app.js` ไว้ในโฟลเดอร์เดียวกัน

## ฟีเจอร์
- **Dashboard** สรุปความคืบหน้ารวม, งาน HIGH ที่เสร็จแล้ว, และ progress bar แยกสถานะ
- **งานทั้ง 30 ข้อ** seed มาจากเอกสารสรุป (13 HIGH / 15 MEDIUM / 2 LOW) พร้อมระดับ หมวด ผู้รับผิดชอบ และสิ่งที่ต้องทำ
- **อัปเดตสถานะ** ได้ 4 สถานะ: ยังไม่เริ่ม / กำลังทำ / ติดขัด / เสร็จ
- **แก้ไข / โน้ต** เปลี่ยนผู้รับผิดชอบและบันทึกความคืบหน้าต่อรายการได้
- **มุมมอง 3 แบบ:** จัดกลุ่มตาม Action Plan (4+1 ระยะ) / ตามระดับ / เรียงตามหมายเลข
- **ตัวกรอง + ค้นหา:** กรองตามระดับ สถานะ และค้นหาข้อความ

## เชื่อมกับไฟล์ Excel All-Links
งานที่มีข้อมูลรายละเอียดในไฟล์ `2026-09-23 - www.tipinsure.com - All Links.html.xlsx` จะมีปุ่ม **📊 ดูข้อมูล Excel** บนการ์ด กดแล้วจะเปิดตารางแสดงข้อมูลของ sheet ที่เชื่อมกับหัวข้อนั้น (เช่น #04 รูปใหญ่ → ตารางรายการรูปทั้งหมดพร้อมขนาด/URL)
- บางหัวข้อมีหลาย sheet (เช่น #14 มีทั้งรายการ URL เสีย และหน้าที่ลิงก์ไปหา) สลับดูได้ที่แท็บด้านบน
- ค้นหา/กรองแถวในตารางได้
- ข้อมูลถูกแตกจาก Excel เป็นไฟล์ JSON ในโฟลเดอร์ `data/` (แสดงตัวอย่าง 300 แถวแรกต่อ sheet เพื่อความเร็ว ดูครบได้ในไฟล์ Excel ต้นฉบับ)

> **สำคัญ:** ฟีเจอร์นี้ต้องเปิดผ่าน web server (เช่น `node server.cjs` แล้วเข้า http://localhost:8777) ไม่ใช่เปิดไฟล์ตรง ๆ แบบ file:// เพราะเบราว์เซอร์บล็อกการ fetch ไฟล์ JSON ผ่าน file://

### วิธีรัน server
```
node server.cjs
```
แล้วเปิด http://localhost:8777 ในเบราว์เซอร์

## การบันทึกข้อมูล
- ข้อมูลที่อัปเดตถูกบันทึกอัตโนมัติใน **localStorage** ของเบราว์เซอร์นั้น (ไม่หายเมื่อปิด/เปิดใหม่)
- ข้อมูลผูกกับเบราว์เซอร์+เครื่องนั้น ถ้าเปลี่ยนเครื่องหรือล้าง cache ข้อมูลจะไม่ตามไป

### Export รายงาน (สำหรับส่ง/นำเสนอ)
ปุ่ม **📄 Export รายงาน** มีให้เลือก 3 แบบ:
- **🖨️ พิมพ์ / บันทึกเป็น PDF** — เปิดหน้ารายงานสวยงาม (dashboard + ความคืบหน้าแยกทีม + ตารางงาน 30 ข้อ) แล้วสั่งพิมพ์ ในหน้าพิมพ์เลือก "Save as PDF" ได้
- **🌐 ดาวน์โหลดรายงาน HTML** — ได้ไฟล์ .html เปิดดู/ส่งต่อได้ (เปิดแล้วสั่งพิมพ์เป็น PDF ได้เช่นกัน)
- **📊 ดาวน์โหลด CSV** — เปิดใน Excel/Google Sheets ได้ (มี BOM ภาษาไทยอ่านได้ถูกต้อง) มีทุกคอลัมน์: #, ระดับ, หมวด, ทีม, สถานะ, ผู้รับผิดชอบ, โน้ต, วันที่อัปเดต

รายงานสะท้อนสถานะ ณ ตอนที่กด (ตามข้อมูลที่บันทึกไว้)

**Export ตามตัวกรอง:** เมนูแบ่งเป็น 2 กลุ่ม
- *รายงานทั้งหมด* — ทั้ง 30 งาน ไม่สนใจตัวกรอง
- *เฉพาะที่กรองอยู่* — export เฉพาะงานที่ตรงกับตัวกรองปัจจุบัน (ระดับ/สถานะ/ทีม/คำค้น) เมนูจะแสดงว่ากรองอะไรอยู่และเหลือกี่งาน รายงานที่ได้จะมีแบนเนอร์บอกเงื่อนไขการกรอง และไฟล์มีคำต่อท้าย `-filtered`

ตัวอย่าง: เลือกทีม = Dev แล้ว export "เฉพาะที่กรอง" จะได้รายงานเฉพาะงานของทีม Dev

### แชร์ข้ามเครื่อง / แบ็กอัป
- **Export JSON** — ดาวน์โหลดไฟล์ข้อมูลปัจจุบัน (แนะนำให้เก็บไฟล์นี้ไว้ในโปรเจกต์เป็นแบ็กอัป)
- **Import JSON** — โหลดไฟล์ที่ export ไว้กลับเข้ามา (ใช้ย้ายเครื่อง หรือให้เพื่อนในทีมเปิดสถานะเดียวกัน)
- **Reset** — ล้างกลับเป็นค่าเริ่มต้น (ควร Export เก็บไว้ก่อน)

## Workflow แนะนำสำหรับทีม
เนื่องจาก localStorage แยกตามเครื่อง ถ้าหลายคนต้องอัปเดตร่วมกัน แนะนำ 1 ใน 2 วิธี:
1. **แบบง่าย:** ให้คนเดียวเป็นเจ้าของไฟล์ อัปเดตแล้ว Export JSON เก็บเข้า Git/ไดรฟ์รวม เป็นแหล่งข้อมูลกลาง
2. **แบบทีม (ถ้าต้องการ real-time หลายคน):** ต่อยอดเป็นฐานข้อมูลจริง (ดูหัวข้อถัดไป)

## แนวทางต่อยอด (ถ้าอยากได้มากกว่านี้)
- **Multi-user real-time:** ย้าย backend ไปใช้บริการ hosted database เช่น Supabase / Firebase — ยังคงเป็น frontend เดิมได้ เปลี่ยนแค่ชั้นบันทึกข้อมูลจาก localStorage เป็น API
- **แจ้งเตือน/มอบหมายงาน:** เพิ่มฟิลด์ due date + ผู้รับผิดชอบจริง แล้วเชื่อม Line Notify / Slack
- **รายงานอัตโนมัติ:** สร้างสรุปรายสัปดาห์ export เป็น PDF/CSV ส่งให้ลูกค้า
- **เชื่อมกับ Excel Project Plan:** map สถานะ "Onsite Implementation Complete" กลับไปที่ชีต Campaign Set Up Tracking

หากต้องการเวอร์ชัน multi-user บอกได้ ผมช่วยวางสถาปัตยกรรมและทำให้ได้
